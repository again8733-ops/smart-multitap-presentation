문제 정의

차별성

BEFORE

기존 멀티탭

  • ✗ 수동으로만 제어 가능
  • ✗ 외출 시 끄지 않으면 전력 낭비
  • ✗ 사용 패턴과 무관하게 동작
VS
AFTER

홈즈AI 스마트 멀티탭

  • ✓ 얼굴 인식 → 자주 쓰는 가전 자동 ON
  • ✓ 사용하지 않을 때 자동 OFF → 전기 요금 절감
  • ✓ 웹에서 수동 제어 가능
  • ✓ 웹에서 절감된 전기 요금 및 사용 전력량 확인
